📖 使用說明

🔍 關鍵字搜尋

1. 在頂部搜尋框輸入關鍵字
2. 下方 Pills 勾選要搜的平台
   （可單選、多選、全選）
3. 點「搜尋」，同時跑所有勾選的平台
4. 結果顯示在下方，點卡片預覽
5. 勾選多部後點底欄批量下載
⚠️ TikTok / 快手 / 抖音 改用 Edge 模擬真人繞過驗證碼，每平台需 10–20 秒。全選時同時啟動 3 個瀏覽器，較慢屬正常。失敗時改用 URL 直接下載。

🖼️ 圖片搜尋

1. 點「圖片搜尋」卡片的上傳區
   或直接拖曳圖片進去
2. AI（qwen2.5vl:7b）自動識別
   圖片內容轉成關鍵字
3. 選擇要搜的平台
4. 點「AI 圖片搜尋」，全網找相關影片
✅ 適合：看到商品、人物、場景，想找相關影片時用

🔗 URL 直接下載

1. 複製任意平台的影片連結
2. 貼到「URL直接下載」卡片
3. 點「預覽影片」確認內容
4. 點「去水印下載」完成
