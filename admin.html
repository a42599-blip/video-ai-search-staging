🍪 平台 Cookies（啟用抖音搜尋 + 下載）
設定步驟（每次換帳號或 cookies 過期才需要做）：

1. 打開 Edge 瀏覽器，安裝擴充功能 「Cookie-Editor」
2. 前往 douyin.com，用手機掃碼登入
3. 點工具列的 Cookie-Editor 圖示 → 右上角點 Export → Export as JSON
4. 複製全部內容，貼到下方輸入框 → 點「儲存 Cookies」

設定成功後，搜尋抖音關鍵字即可正常顯示結果；下載也會更穩定、有聲音。
